MODULE 2.2

⚖️ Quick vs. Comprehensive modes

With each analysis, you make a choice: fast and cheap or deep and comprehensive. This module clears up the confusion — it shows what changes (and what doesn’t), the models behind it, the costs side by side, and a simple rule for deciding.

Detailed content

1

🔢 The key difference

There’s a common myth that Comprehensive mode “generates more stuff.” That’s not true. There’s only one difference—the research depth. Quick runs about 9 searches; Comprehensive runs about 18. The 15 final documents are exactly the same.

💡 The core idea

Think of it like an essay: both modes write the same number of pages with the same structure. Comprehensive simply read twice as many sources before writing — so the pages are better supported, with more detail and nuance.

✓ What CHANGES between modes

  • ✓Number of searches (9 vs. 18)
  • ✓Depth and nuance of the documents
  • ✓Execution time
  • ✓Cost

✗ What does NOT change

  • ✗The number of documents (always 15)
  • ✗File types (PPTX, DOCX, PNG)
  • ✗The structure of the output/ folder
  • ✗The synthesis model (always the same Gemini)
2

🐇 Quick Mode

Quick is the default mode — you don't even need to type the flag. It's fast (2-3 minutes) and very inexpensive (~US$ 0,05). Think of it as your tool for screening.

⌨️ Running in Quick mode

# Estas duas linhas fazem a mesma coisa
python -m strategy_factory.main run "Stripe"
python -m strategy_factory.main run "Stripe" --mode quick

# ~9 buscas · 2-3 min · ~US$ 0,05

🎯 When to use Quick

  • Batch triage — compare several companies quickly
  • First pass — get an overview before deciding
  • Testing and study — when costs need to be kept to a minimum
  • Companies you may not even dig deeper into

💡 Tip — always start here

For the overwhelming majority of cases, Quick already delivers a great draft. Move up to Comprehensive only when the result is really for external use (client, leadership).

3

🐢 Comprehensive Mode

Comprehensive is the in-depth pass. It takes 5 to 10 minutes and costs about US$ 0,50 — ten times more than Quick, but still less than a dollar. This is the mode for the company you're going to actually present.

⌨️ Running in Comprehensive mode

# A flag é obrigatória aqui
python -m strategy_factory.main run "Stripe" --mode comprehensive

# Com contexto, o resultado fica ainda melhor
python -m strategy_factory.main run "Stripe" \
  --mode comprehensive \
  --context "B2B payments, fintech"

# ~18 buscas · 5-10 min · ~US$ 0,50

✓ It’s worth it when

  • ✓The result will go to a real client
  • ✓You're going to present to the board
  • ✓The company is complex or poorly documented
  • ✓You want as much supporting evidence as possible

✗ It’s overkill when

  • ✗You're only screening many companies
  • ✗It’s a test or a quick study
  • ✗You haven't decided whether to use the result yet
  • ✗Time is more critical than depth

💡 Tip — even 10x more expensive is still pennies

"Ten times more expensive" sounds like a lot, but it’s the difference between 5 and 50 cents. When the result matters, it’s the best investment you’ll make that day.

4

🧠 The models behind it

Why does Comprehensive cost more? Because it uses more expensive and powerful AI models for research. Understanding which models are used in each mode explains the cost.

🐇

Quick → sonar only

Uses only the model sonar from Perplexity — cheap and fast. It’s enough for a good overview.

🐢

Comprehensive → sonar + sonar-pro + deep-research

Combines sonar, sonar-pro e sonar-deep-research. Stronger (and more expensive) models that do background research.

✍️

Synthesis → always Gemini

In both modes, the writing uses the same model: gemini-2.5-flash. That’s why the documents have the same format—the source material changes, not the writer.

🔑 Summarizing the models

  • Research (Quick): sonar
  • Research (Comprehensive): sonar + sonar-pro + sonar-deep-research
  • Summary (always): gemini-2.5-flash

6

🧭 How to choose

The winning strategy is simple: screen several companies with Quick and go deeper only on the one you choose with Comprehensive. And when you dig deeper, reuse the research you already have.

🌳 Decision tree

Você vai apresentar/entregar este resultado?
│
├─ NÃO  → 🐇 Quick (triagem, estudo, primeira passada)
│
└─ SIM  → 🐢 Comprehensive
          │
          └─ Já rodou Quick nesta empresa antes?
             │
             ├─ SIM → --mode comprehensive --skip-research?
             │        (avalie: pesquisa básica já serve?)
             │
             └─ NÃO → --mode comprehensive (pesquisa do zero)

⏱️ The recommended workflow, step by step

1

Triage in Quick

Run run "Company" for each candidate. It costs pennies in total.

2

Choose the winner

Read the quick drafts and decide which company deserves an in-depth analysis.

3

Go deeper on just this one

Run --mode comprehensive on the selected one. Use --skip-research if basic research is enough.

🎯 In short

Keep filtering cheap, and spend more only where it counts. This balance between Quick and Comprehensive keeps your costs tiny without sacrificing quality when it matters.
