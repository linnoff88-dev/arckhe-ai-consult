MODULE 1.3

🖥️ Your first report (web mode)

It's time to generate for real. This module walks you through the easiest way: the web interface. You launch the app with one command, get to know each part of the screen, enter the company name, follow the 3 phases live, and download the finished package—pointing and clicking, without memorizing commands.

Detailed content

1

▶️ Start the web app

The web mode is the most user-friendly way to use the tool — and deploys with a single command. Right after that, the browser opens automatically on the tool’s page.

⌨️ Bringing up the interface

# lembre de ativar o venv antes
python -m strategy_factory.webapp

# o navegador abre em:
http://localhost:8888

This is the only command you need to use the tool on the web.

✓ What it should look like

  • ✓The venv is active (it appears (venv) at the start of the line)
  • ✓You run the command and the browser opens automatically
  • ✓The page loads in localhost:8888

✗ If something gets stuck

  • ✗"Port in use"? It finds another one on its own—or use --port 9000
  • ✗“Module” error? The venv isn’t activated
  • ✗Nothing opened? Type the address manually into the browser’s address bar

💡 Tip — leave the terminal open

While you use the interface, the terminal needs to stay open and run the command—it’s what keeps the app running. To shut it down afterward, just close the terminal or press Ctrl+C in it.

2

Before running it, it’s worth getting to know the screen. It is simple by design: basically a field, a selector, an optional field, and a button. Getting to know each part gives you confidence for your first analysis.

Illustrative recreation of the screen — not an actual screenshot of the app.

📋 The four parts of the screen

  • Company field — where you enter the name (the only required field)
  • Mode selector — Quick (fast and inexpensive) or Comprehensive (in-depth)
  • Context field — optional tips on industry, company size, and business model
  • Start button — launches the analysis and starts the 3 phases
3

🏷️ Enter the company

This is the only required field. Enter the name of the company you want to analyze — for example, "Stripe". It’s the starting point for the entire analysis.

📂 The name becomes the results folder

# você digita:        Stripe
# os arquivos vão para:
output/stripe/
├── markdown/        (15 documentos)
├── presentations/   (2 apresentações)
├── documents/       (2 relatórios)
└── mermaid_images/  (diagramas)

The name you enter becomes the name of the folder (in lowercase) where everything is saved.

✓ Good examples

  • ✓The company’s familiar name: "Stripe," "Nubank"
  • ✓The name the market knows it by
  • ✓One company per analysis

✗ Avoid

  • ✗Vague names or little-known abbreviations
  • ✗Leave the field blank (it's required)
  • ✗Mixing multiple companies in the same field

💡 Tip — ambiguous name? Use the context

If the name could be confusing (more than one company has that name), don’t worry: the context field in the next section helps you specify exactly which company you mean.

4

💬 Add context

The context field is optional, but it makes a difference. With a few details — industry, size, business model — you help Perplexity research much more accurately.

✍️ Examples of good context

# exemplos de contexto útil
fintech, B2B, 200 funcionários
varejo de moda, e-commerce, mercado brasileiro
SaaS de RH, foco em PMEs, série A

The more specific you are, the better the result — especially for lesser-known companies.

1

Enter the sector

E.g., fintech, retail, healthcare, education. This already narrows the research considerably.

2

Specify the company size and model

E.g., B2B or B2C, number of employees, stage (startup, Series A...).

3

Specify the market, if helpful

E.g., Brazilian market, Latin America. Clears up ambiguity about the name.

💡 Tip — recommended for lesser-known companies

For well-known brands, the name alone is enough. But for local, new, or commonly named companies, context is what separates an accurate report from a generic one.

5

📊 Track progress

After starting, a bar shows progress through the three phases in real time. You can see exactly what’s happening and tell as soon as the package is ready.

1

Research — Perplexity collects data

The bar shows the collection of information about the company and its industry.

2

Summary — Gemini writes

You watch the documents being generated one by one.

3

Generation — the files are assembled

The final step builds presentations, Word documents, and diagrams on your computer.

⏱️ How long it takes

  • Quick mode (fast): about 2 to 3 minutes
  • Comprehensive mode (in-depth): about 5 to 10 minutes
  • Practical tip: don't close the tab until you see the package completed

💡 Tip — order matters

The phases run in sequence: Synthesis starts only when Research is finished, and Generation starts only at the end. That’s why the bar moves in stages—it’s normal for each phase to take a little while before moving on to the next.

6

📥 Download the files

This is the end goal: have the files on hand. When it finishes, the screen shows download links for each deliverable — and everything is also saved on your machine.

🔗 Download on screen

Each deliverable (documents, presentations, Word files, and diagrams) has its own link to download it directly from the interface.

💾 Saved on your machine

Everything is also saved in output/company-name/, even if you close the browser.

👀 Read on screen

You can view the contents of the markdown documents directly in the interface before downloading them.

📦 Complete package

15 documents + 2 presentations + 2 reports + diagrams, ready to review and present.

📂 Where to find everything on your computer

output/stripe/
├── markdown/         (15 .md — os documentos de texto)
├── presentations/    (2 .pptx — resumo e completa)
├── documents/        (2 .docx — relatório e proposta)
└── mermaid_images/   (.png — os diagramas)

Even if you don’t download them from the page, all the files are here.
