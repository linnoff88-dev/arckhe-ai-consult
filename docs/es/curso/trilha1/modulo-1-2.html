🔑 Requisitos previos e instalación

Ahora vamos a poner la herramienta en marcha en tu máquina. Este módulo es práctico y paso a paso: qué instalar antes, cómo obtener las dos claves de API gratuitas, dos formas de instalar (automática y manual), dónde pegar las claves y cómo confirmar que todo funcionó, sin gastar nada.

Contenido detallado

1

🧰 Lo que necesitas

Antes de ejecutar cualquier comando, reúne tres cosas. Tenerlas listas antes de empezar evita el error más común de principiante: quedarse atascado a mitad de la instalación porque faltaba algo básico.

🐍
Python 3.9+

El lenguaje que ejecuta la herramienta. Descárgalo en python.org/downloads.

🔐
2 claves de API

Una de Perplexity y una de Gemini. Obtienes ambas en los próximos temas.

⌨️
Una terminal

Símbolo del sistema en Windows; Terminal en Mac/Linux. Es donde escribes los comandos.

⚠️ La trampa de Windows

Al instalar Python en Windows, hay una casilla que es fácil pasar por alto y que causa la mitad de los problemas de quienes empiezan:

  • ✗Olvidar marcar "Add Python to PATH" en la primera pantalla del instalador
  • ✗Resultado: la terminal no "detecta" Python y da el error "comando no encontrado"
  • ✗Solución: reinstalar Python y marcar la casilla esta vez

💡 Consejo — comprueba la versión de Python

En la terminal, escribe python --version (o python3 --version). Si aparece 3.9 o superior, ya estás listo. Si da error, significa que falta instalarlo — o marcar la opción PATH.

2

🔎 Clave de Perplexity

La primera de las dos claves viene de Perplexity — la IA que realiza la investigación (Fase 1). Sin ella, no se genera ningún documento. El proceso tarda unos 2 minutos.

1

Accede al panel de API

Abre perplexity.ai/settings/api en el navegador.

2

Crea una cuenta (si todavía no tienes una)

Es gratis para empezar. Inicia sesión con normalidad.

3

Haz clic en "Generate API Key"

La clave aparece en pantalla. Empieza con pplx-. Cópiala y guárdala.

🔑 Cómo se ve la clave

# formato (exemplo — a sua será diferente)
pplx-1a2b3c4d5e6f7g8h9i0j...

Trata esta clave como una contraseña: quien la tenga puede gastar tu crédito.

🛡️ Consejo — obligatoria para la Investigación

Esta es la clave de la Fase 1 (Investigación). Si falta o es incorrecta, la herramienta ni siquiera llega a escribir los documentos: se detiene al principio con un error de clave.

3

✨ Clave de Gemini

La segunda clave viene de Google Gemini — la IA que redacta los documentos (Fase 2). Es gratis para empezar y puedes obtenerla en Google AI Studio con unos pocos clics.

1

Accede a Google AI Studio

Abre aistudio.google.com/apikey.

2

Inicia sesión con tu cuenta de Google

Te sirve la misma cuenta de Google que ya usas en el día a día.

3

Haz clic en "Create API Key"

La clave empieza con AIzaSy. Cópiala y guárdala junto con la otra.

✓ Ahora tienes

  • ✓La clave de Perplexity (pplx-...)
  • ✓La clave de Gemini (AIzaSy...)
  • ✓Las dos guardadas en un lugar seguro

✗ Evita estos errores

  • ✗Cambiar las claves de lugar (cada una va en su campo)
  • ✗Copiar con un espacio al principio o al final
  • ✗Publicar la clave en un chat, una captura de pantalla o un repositorio público

💡 Consejo — dos cuentas, dos sitios

Las claves provienen de sitios diferentes (Perplexity y Google) y cada una tiene su propio crédito. Ambas tienen un plan gratuito para que pruebes antes de gastar de verdad.

4

🚀 Instalación automática

Con el proyecto descargado, hay un atajo que hace casi todo por ti: un solo comando. Es el camino recomendado para quien no quiere modificar cada etapa a mano.

⌨️ El comando mágico

# na pasta do projeto
python setup.py

Este comando inicia un asistente que prepara todo el entorno de una sola vez.

✓ Qué hace setup.py por ti

  • ✓Crea el entorno virtual (una "caja" aislada solo para este proyecto)
  • ✓Instala todas las dependencias que la herramienta necesita
  • ✓Genera el archivo .env en blanco, listo para que pegues las claves

💡 Consejo — si falla el modo automático

En algunas computadoras el atajo puede fallar (versión diferente de Python, permisos, etc.). No hay problema: el siguiente tema muestra la instalación manual, que realiza exactamente los mismos pasos, solo que uno por uno.

5

🛠️ Instalación manual

Si prefieres controlar cada paso — o si el proceso automático falló — puedes instalarlo manualmente. Son cuatro comandos simple. Además, entiendes lo que ocurre entre bambalinas.

⌨️ Paso a paso en la terminal

# 1) Criar o ambiente virtual (a "caixa" isolada do projeto)
python3 -m venv venv

# 2) Ativar o ambiente
source venv/bin/activate        # Mac / Linux
.\venv\Scripts\activate         # Windows

# 3) Instalar as dependências
pip install -r requirements.txt

# 4) Criar o arquivo de chaves a partir do exemplo
cp .env.example .env

Ejecútalo en orden. El paso 2 cambia según tu sistema: usa solo la línea que corresponda.

✓ Qué es el "venv"

  • ✓Un entorno aislado solo para este proyecto
  • ✓Evita conflictos con otros programas de Python
  • ✓Mantiene todo organizado y fácil de eliminar después

✗ El error n.º 1 de los principiantes

  • ✗Olvidar activar el venv antes de usar la herramienta
  • ✗Síntoma: error de «módulo no encontrado»
  • ✗Solución: vuelve a ejecutar el comando de activación del paso 2

💡 Consejo — activa siempre el venv antes

Cada vez que abras una terminal nueva para usar la herramienta, ejecuta primero el comando de activación. Cuando el venv está activo, suele aparecer (venv) al inicio de la línea: es la señal de que todo está bien.

6

📝 Configura el .env

El archivo .env es donde tus claves «entran» en el programa. Ábrelo en un editor de texto y completa los dos campos. Es el paso que conecta la herramienta con las IA.

📄 Cómo debe quedar el .env

# cole cada chave depois do = (sem aspas, sem espaços)
PERPLEXITY_API_KEY=pplx-1a2b3c4d5e6f7g8h9i0j...
GEMINI_API_KEY=AIzaSy1a2b3c4d5e6f7g8h9i0j...

Reemplaza los ejemplos por tus claves reales. Guarda el archivo después de editarlo.

✓ Hazlo así

  • ✓Pega la clave justo después de =, sin espacio
  • ✓Una clave por línea, exactamente con esos nombres
  • ✓Guarda el archivo antes de ejecutar la herramienta

✗ Nunca hagas

  • ✗Poner comillas o espacios extra alrededor de la clave
  • ✗Renombrar o borrar los nombres de los campos
  • ✗Compartir o subir el .env para GitHub

🔒 Consejo — el .env es privado

Este archivo guarda tus claves en texto sin cifrar. Nunca lo envíes por correo electrónico, chat o repositorio público: quien lo tenga puede gastar tu crédito. Debe quedarse solo en tu máquina.

7

✅ Confirmar que funcionó

Antes de gastar un centavo, conviene hacer una prueba de simulación. Confirma que la instalación y las claves estén correctas — sin realizar ninguna llamada de IA de pago.

⌨️ La prueba sin costo (dry-run)

# com o venv ativado
python -m strategy_factory.main run "Stripe" --dry-run

La flag --dry-run simula la ejecución: no se cobra nada ni se llama a ninguna IA real.

✓

¿Se ejecutó sin error de clave?

Entonces está todo bien: Python, entorno y .env configurados. Estás listo para el Módulo 1.3.

✗

¿Te dio un error de clave?

Vuelve al tema 6: probablemente sobra un espacio, se cambió el nombre de un campo o no se guardó el archivo.

🎯 En resumen

Si el dry-run salió bien, la herramienta está instalada y configurada. En el próximo módulo la ejecutarás de verdad — desde la interfaz web, sin ningún comando — y generarás tu primer informe.
